## Contratos conferidos e dependências reais

Swagger de homologação consultado em `/openapi/v1.json`, sem alterar a cópia versionada do Swagger.

1. **C32 — dados pessoais/documentais adicionais:** GET identificação já traz `personalDetails`; leitura foi aproveitada. No Admin não há escrita de personalDetails/preferência de contato. Número/metadata documental não pode ser substituído por máscara: a leitura administrativa de edição traz `personalDocuments` com valor mascarado, não um snapshot completo para reconstruir com segurança o JSON do documento informado. Disponibilizar leitura/escrita administrativas dos campos aprovados (estado civil, gênero, nacionalidades, nascimento, filiação, preferência e metadados documentais), preservando evidências e campos ocultos. Não usar endpoints `/client` com token do admin e não inventar gravação local.
2. **C33 — segurança:** UpdateUserRequest permite nome/e-mail/workspace; não inclui status da senha nem 2FA. O endpoint público de redefinição existente envia código. O desenho pede link enviado ao cliente pelo Admin. Status/2FA e Redefinir ficam indisponíveis até existir contrato administrativo compatível. Nenhum código ou e-mail foi enviado para simular essa ação.
3. **C11 — CND:** `CND_CONDOMINIO` não existe no catálogo consultado. O card permanece visível com Enviar indisponível; ativar upload exige cadastro do tipo/document definition pelo backend, se o produto mantiver esse documento opcional. Não bloqueia o salvamento do bem.
4. **C11 — Adicionar característica:** o DTO do imóvel só contém os campos fixos já integrados. Não há coleção genérica para características adicionais; ação do desenho fica indisponível até definição/persistência correspondentes.
5. **C10.3/C10.4 — consórcio:** DTO não contém início, data da contemplação, carta liberada e status de utilização. O front mostra ausência real; não substitui esses fatos por data de criação, valor da carta ou status de quitação. Confirmar modelo se esses dados continuarem necessários.

Não reabrir como endpoints ausentes: busca bancária, criação/edição bancária, upload bruto, vínculo/desvínculo patrimonial, fotos, documentos temporários, edição profissional/financeira e preferências já estão disponíveis.
